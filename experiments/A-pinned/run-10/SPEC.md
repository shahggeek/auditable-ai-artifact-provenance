IFR3 (FR3): From the list or detail view, a visitor can add a pet with availability status "available" to a session-scoped Cart; the add action is not offered for unavailable pets.

IFR5 (FR5): On successful order placement, the system decrements each ordered Pet's inventory quantity by the quantity of that pet in the order, as a single atomic update per order.

IFR8 (FR8): An authenticated user with the admin role can create a Pet with name, species, price, photo, description, and quantity, and can edit any of those fields, including quantity, on an existing Pet.
